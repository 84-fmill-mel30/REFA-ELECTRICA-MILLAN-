CÓMO INTEGRAR EN TU PROYECTO ANDROID STUDIO:
================================================================

PASO 1: COPIAR ARCHIVOS JAVA
-----------------------------
Copia todos los archivos .java a:
app/src/main/java/com/refaccionaria/millan/

(Ajusta el package name si tu proyecto usa otro)

PASO 2: COPIAR LAYOUTS XML
---------------------------
Copia los archivos .xml a:
app/src/main/res/layout/

PASO 3: ACTUALIZAR build.gradle
--------------------------------
Abre: app/build.gradle

Agrega en dependencies:
    implementation 'me.dm7.barcodescanner:zxing:1.9.13'
    implementation 'androidx.recyclerview:recyclerview:1.3.2'

Luego: Sync Now

PASO 4: ACTUALIZAR AndroidManifest.xml
---------------------------------------
Agrega los permisos de cámara:
    <uses-permission android:name="android.permission.CAMERA" />
    <uses-feature android:name="android.hardware.camera" android:required="true" />

Agrega las activities:
    <activity android:name=".RefaccionariaMainActivity" />
    <activity android:name=".EscanerActivity" />
    <activity android:name=".AdminActivity" />

PASO 5: COMPILAR Y PROBAR
--------------------------
1. Build → Rebuild Project
2. Conecta tu celular por USB
3. Run ▶️
4. ¡Prueba la app!

CÓMO USAR LA CÁMARA COMO ESCÁNER:
================================================================

1. En pantalla principal, presiona botón "📷 Escanear"
2. Apunta la cámara al código de barras
3. La app detecta automáticamente el código
4. Si el producto existe, muestra info
5. Si no existe, puedes agregarlo desde Admin

DESDE PANEL ADMIN:
------------------
1. Presiona "📷 Escanear Código de Barras"
2. Escanea el producto
3. El código se llena automáticamente
4. Completa descripción, precio, stock
5. Guarda

ACTUALIZAR PRECIOS CON ESCÁNER:
-------------------------------
1. Escanea el código
2. Se abre el producto
3. Edita el precio
4. Guarda cambios
