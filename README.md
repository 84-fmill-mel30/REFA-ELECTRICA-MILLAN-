CÓMO USAR:
----------
1. Abre "index_refaccionaria.html" en tu navegador
2. Usa el micrófono para buscar por voz
3. Di: "¿Tienes bobina para Jetta?" o "Foco H4"
4. El sistema buscará y mostrará productos

PANEL ADMINISTRADOR:
-------------------
1. Abre "admin_refaccionaria.html"
2. Agrega productos nuevos
3. Edita precios y stock
4. Elimina productos
5. Filtra y busca en el inventario
